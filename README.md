# Pojok Foto

Photobooth retro di browser: pilih template bingkai, jepret dengan hitung mundur, beri filter film dan stiker, lalu simpan ke galeri atau cetak PDF. Foto diproses di perangkat dan tidak diunggah.

## Teknologi
Next.js (App Router) + TypeScript, Tailwind CSS, Canvas API, jsPDF.

## Menjalankan
```
npm install
npm run dev
```
Buka http://localhost:3000

## Deploy
Push ke `main`. GitHub Actions membangun dan memasang ke GitHub Pages (Settings → Pages → Source: GitHub Actions).
